# 持仓由交易流水按日期回放得到

状态：已采纳。

持仓页只允许新增和删除已成交交易，不再提供“添加持仓”“编辑持仓”或“移除持仓”。交易记录包含账户、标的、交易日、买卖方向、数量、成交价、手续费、税费和备注。历史持仓快照只回放 `trade_date <= as_of` 的交易，因此后来发生或后来补录为未来日期的交易不会进入更早日期。

剩余成本采用 FIFO。买入批次的单位成本包含手续费和税费；卖出按最早批次扣减，卖出手续费和税费从已实现收益中扣除。新增卖出和删除交易都要重新验证完整账本；如果任一时点会出现卖出数量大于可用数量，请求以冲突返回，不写入半套状态。

该账本仍是研究型本地账本，不维护现金、分红、拆并股、配股、转托管、外汇或券商对账。页面和文档不能把它描述为券商级资产真源。

旧版 `accounts + positions` 文件在首次读取时迁移为 schema v2。每条旧持仓转换为一笔 `migration_source=legacy_position` 的期初买入交易，保留账户、标的、原数量、原平均成本、参考买入日期和备注；持仓数组随后移除。迁移使用原子文件替换，避免重复转换。
