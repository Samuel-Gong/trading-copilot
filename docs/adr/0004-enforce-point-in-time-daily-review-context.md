# 历史复盘上下文统一使用截止日语义

状态：已采纳。

用户选择非最新交易日时，所有可变事实都必须证明其时间不晚于复盘日。不同数据使用以下截止字段：

- 交易以 `trade_date <= business_date` 回放。
- 日 K、指数和技术指标只读取 `date <= business_date`。
- 财务数据只保留 `announce_date` 或等价公告时间不晚于复盘日的记录；表中没有公告时间时，历史复盘不注入该表。
- 新闻使用本地归档中的 `published_at`，截止到北京时间复盘日 `23:59:59`；未来新闻和发布时间未知的新闻都排除。
- 时序概念或行业扩展数据选择不晚于复盘日的最近分区；没有生效日期的 snapshot 扩展表不进入历史大盘复盘。

无法证明时间归属时采用 fail-closed，表现为数据缺口，而不是回退到当前值。新闻上游抓取失败采用 fail-open：复盘继续运行，但只使用本地归档中仍满足截止条件的条目，并在档案中保留源状态和错误。

策略是有意的例外：历史行情使用截止日数据，但策略代码和参数始终使用运行复盘时的最新版本，不保存历史策略版本。每日复盘会冻结启动时选股页策略池中的策略 ID 和名称，保证候选来源可核对；它冻结的是策略选择，不是策略代码版本。界面和报告应把结果描述为“当前策略的历史回看”，不能暗示它复现了当时实际运行的策略。
