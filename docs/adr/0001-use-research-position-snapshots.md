# 首版持仓采用研究快照而不是交易事件账本（已废弃）

状态：已由 [ADR-0003](./0003-derive-historical-positions-from-trades.md) 取代。

参考系统能够从成交、现金和公司行动重建持仓，但当前 TickFlow Stock Panel 的真源是行情仓库、客观分析和本地用户配置。首版因此保存多账户当前持仓快照，并把它作为每日研究上下文；不引入交易事件、现金、税费和券商对账语义。持仓可记录一个参考买入日期，用于说明建仓时间并随每日复盘冻结，但它不代表成交流水，也不参与平均成本、估值或盈亏计算。这样能直接复用现有分析与报告路径，同时避免一套不完整的账本被误认为可核对的交易事实源。若未来需要券商级账本，应新增明确的导入、对账和迁移设计，而不是在快照字段上继续叠加事件语义。

该决定解决了首版交付范围，但无法回答“某个历史交易日实际持有什么”，并且会把后来录入的当前持仓带入更早日期。因此当前实现不再允许直接维护持仓快照。
